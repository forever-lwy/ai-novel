# AI Novel

私有部署的 AI 小说创作工作台。支持原创、续写、同人和改写，导入已有小说或从设定开始，持续维护正文、人物、世界观、剧情摘要与伏笔。

## 可以做什么

- 导入 TXT／EPUB，选择常用分章规则；无章节标题的小说可按设定字数分章，也可保存自定义规则，或勾选章节名让 AI 生成规则。确认目录后逐段整理资料，原创可以直接开始写作。导入预览和已有章节均可用 AI 核对标题，先检查建议再选择应用。
- 流式生成正文，章节标题留空时根据本章内容自动命名，手动填写时直接使用；在当前正文界面暂停、停止或显式重试；原生思考摘要、预设思考和工具过程按对应正文位置显示，正文先保存，再整理资料。
- 编辑已有正文直接保存到当前故事线，保留已有资料；AI 改写整章或选段、重新生成章节时另开故事线。章节末尾可手动建立分支，各类新分支均可命名、之后重命名，通过分支树选择故事线；支持删除分支和版本回退。
- 删除当前故事线中的单章或资料条目，清除某章已提取资料，或单独重新提取该章；操作留下版本，可回退恢复。
- 穿越到小说中，以原创角色或已有角色体验剧情；关键节点显示选项，也可自由输入行动。每章按累计字数收束，章末选择承接到下一章。
- 有原作时，AI 可参考原作后续剧情摘要与人物、物品等资料，并按关键词、章节路径、行号或段号查阅原文。
- 查看人物与世界资料、原文出处、地点关系图、剧情摘要和伏笔，人工纠正、锁定或合并资料。
- 自动绘制新人物立绘，为人物、各类实体与地图生成图片；按章节或选段生成剧情 CG。手动绘制和重新绘制时可看缩略图自选参考图，也可自动选择或不用参考图；图册按人物、剧情范围和资料分组，点击封面查看不同版本，支持启用、停用、删除、AI 修改、缩放与全屏查看。
- 为不同任务选择供应商和模型，编辑提示词预设、消息块与变量，新建或复制时命名，之后可重命名；查看实际请求诊断和作者生成过程。
- 添加自定义 JavaScript 工具、连接 MCP、导入技能；模型先看简介，按需读取完整参数、技能正文和附件，再执行工具。配置入口在“设置 → 工具与技能”。
- 导出正文、备份与恢复完整作品，或确认后删除作品及相关数据。

当前采用单用户、单实例部署。完整能力、未实现方向与验证边界见 [项目状态](PROJECT-STATUS.md)；详细操作见 [使用指南](docs/USAGE.md)。

## 快速运行

需要 **Node.js 24 或更新版本**。

### 本地开发

新实例首次启动前，复制 [.env.example](.env.example) 为 `.env`，取消 `INITIAL_PASSWORD` 的注释并填写自己的长密码：去除首尾空白后至少 12 位，不能使用常见弱密码。已有 `.env` 时直接编辑，保留其他配置；已有登录密码的数据目录无需提供初始密码。

```sh
npm ci
npm run dev
```

打开 [开发工作台](http://127.0.0.1:5173)，使用配置的密码登录。网页和 API 默认只监听本机，Vite 将 `/api/` 请求代理到 `127.0.0.1:4317`。

### 生产运行

```sh
npm ci
npm run build
npm start
```

新实例同样须在启动前配置 `INITIAL_PASSWORD`。打开 [工作台](http://127.0.0.1:4317)，直接使用该密码登录。服务同时提供 API 和构建后的网页，不需要另外运行 Vite。

设置通过进程环境或 `.env` 提供，服务启动时会自动读取 `.env`。首次无密码的数据目录必须提供有效的 `INITIAL_PASSWORD`，缺失、为空或不合规则时停止启动，不在网页上设置初始密码。构建后的生产入口默认使用 `NODE_ENV=production`，开发源码入口默认使用 `development`，也可在 `.env` 明确设置。

| 配置项 | 默认值与用途 |
| --- | --- |
| `HOST` | `127.0.0.1`，服务监听地址 |
| `PORT` | `4317`，API 与生产网页端口 |
| `DATA_DIR` | `./data`，数据库、原文件及加密密钥目录 |
| `INITIAL_PASSWORD` | 仅首次无密码的数据目录必填，至少 12 位有效字符；已有密码不被重启配置覆盖，改密使用账号安全页面 |
| `PUBLIC_ORIGIN` | 公网部署的 HTTPS 来源，例如 `https://novel.example.com`，不带子路径、查询参数或凭据 |
| `COOKIE_SECURE` | 配置 `PUBLIC_ORIGIN` 后自动启用 Secure Cookie，并拒绝显式 `false`；本机 HTTP 使用可留空 |
| `TRUSTED_PROXIES` | 默认不信任代理头；只填写实际代理的 IP／CIDR，多个值以逗号分隔 |
| `OUTBOUND_ALLOWED_ORIGINS` | 生产模式默认只连接 HTTPS 公网地址；设置后只允许列出的来源，HTTP／私网网关也须明确列入，多个值以逗号分隔 |

开发时若更改 API 的 `PORT`，还需同步调整 [vite.config.ts](vite.config.ts) 中的代理目标。生产运行不使用开发代理。

### Docker／NAS

```sh
docker compose up -d --build
```

[Compose](compose.yaml) 默认绑定主机 `127.0.0.1:4317`，数据持久化到 `novel-data` 卷的 `/app/data`。空数据卷首次运行前在 `.env` 填写 `INITIAL_PASSWORD`，已有完整数据卷保留原密码、作品和独立 API 密钥，无需重新初始化。初始化成功后可从 `.env` 移除初始密码；密码含 `$` 时按 [安全部署](docs/DEPLOYMENT.md#启动与初始密码) 的单引号规则填写。

通过互联网访问时，使用反向代理提供 HTTPS，设置 `PUBLIC_ORIGIN=https://你的域名`，后端端口继续只绑定本机。代理必须覆盖转发头，核实实际连接来源后设置 `TRUSTED_PROXIES`，详见 [安全部署](docs/DEPLOYMENT.md)。SQLite 数据必须放在服务主机本地存储，不要将运行中的数据库放在 SMB／NFS 共享目录。Docker 与目标 NAS 的实机验收情况见 [项目状态](PROJECT-STATUS.md#当前限制与未验证部分)。

## 开始创作

1. 新建作品，打开“设置”。在“供应商连接”填写 API 前缀、协议和密钥，再在“任务模型”为正文写作、摘要压缩、资料提取选择模型；获取列表后可按名称或 ID 搜索，模型列表不可用时可手动填写模型名。
2. 原创填写设定后直接写作，无需预先规划。已有作品上传 TXT／EPUB，检查分章后开始整理。
3. 顶部“继续创作”可直接打开写作窗口，手机无需先新建章节；默认即可使用全部创作功能；顶部“阅读视图”只隐藏思维链和工具调用过程。发起生成后实时查看正文，完成先保存，再整理资料；继续下一章前需完成上一章资料整理。资料失败时只重试整理，也可在作者任务页手工修正。手机滚动阅读时顶部工具栏全部收起，停下轻点屏幕中部展开；电脑保留最上方 Logo 栏，只收起功能栏及正文操作区，上滚或移近工具栏展开。收起部分以覆盖方式显示，不推动正文。
4. 需要不同走向时，在章节末尾点击“从此章节分支”；改写或重新生成会保留原线。同一章反复重新生成会从共同的上一章分出同级路线。手动编辑已有正文不会开分支或自动更新资料，需要时在“章节操作”重新提取。上方“分支树”每章显示一个节点，共用章节合并，故事线名称在末章下方；点击名称切换故事线，点击章节打开正文。作者可在侧栏重命名主线或分支、删除当前非主线分支。世界资料、人物位置、搜索与图册始终使用当前故事线的完整资料，包含秘密与未来设定；切换阅读视图不改变资料范围和编辑入口。

在“设置 → 任务模型 → 资料提取”可选择提示词 JSON（默认）、结构化输出（JSON Schema）或工具调用（填写参数），后两种需要模型与网关支持。工具模式收到提交参数即完成，三种方式都检查原文依据。也可开启提取自动重试，设置次数和间隔，只重试失败片段。任务模型分别配置正文写作、摘要压缩和资料提取；剧情规划功能已移除，世界设定和伏笔编辑保留。

在作品中点击“穿越体验”，选择角色、起点章节和入场要求。程序建立独立 RPG 故事线，原作保留；模型调用询问工具时停下等待，选项和已生成文字可在刷新后恢复。操作与恢复规则见 [穿越体验](docs/USAGE.md#穿越体验rpg)。

供应商连接与任务模型分别保存；参数按“任务用途＋供应商＋模型”独立保存。支持 OpenAI Chat Completions、OpenAI Responses、Google Gemini 和 Claude Messages；填写 API **前缀**，程序不会自动补 `/v1`。具体配置与参数规则见 [使用指南](docs/USAGE.md#模型服务)。

Gemini 可按需开启“工具参数流式”，让支持该能力的模型／网关逐段返回结果工具中的正文；开关默认不发送，真实工具仍等待完整参数后执行，支持范围见[模型连接说明](docs/MODEL-CONNECTIONS.md#参数发送规则)。

“提示词编排”采用“通用框架＋任务提示词”，支持正文、资料提取、摘要压缩和生图提示词。通用内置仅有 **通用综合 · 中性叙事**；任务保留原始默认与 v3。通用框架处理交付通道，任务负责职责、素材边界和结果格式。完整预览不调用模型，预览与实际发送共用编译流程；上下文超限在发送前停止，不隐式重试生成请求。

“生图与自动插画”复用供应商连接，支持 OpenAI 兼容 Images、Gemini 和 Together。手动绘图先由文字 AI 编写专用提示词，CG 同时参考本章完整前后文、前两章全文、此前摘要和相关资料；可独立选择优化模型，默认使用摘要压缩或写作模型。写作中的新自动 CG 直接使用写作 AI 根据其上下文给出的最终提示词。CG 在模型支持时自动选择出场人物的已有立绘作为参考；手动绘制和重新绘制窗口也可自己勾选当前故事线已启用的图片，或明确不用参考图，作者选择优先。尺寸、画幅和分辨率可选择由 AI 决定；参数按接口与型号显示。新人物自动立绘默认开启，自动 CG 默认关闭。写作 AI 提交完整请求后即可后台生图，只有实际需要的立绘未完成时才等待；正文保存、资料确认后关联同一张图片。写作页面和图册可查看进度，失败可单独重试。操作及各模型参数见 [插画与故事图册](docs/USAGE.md#插画与故事图册)。

模型资料可能遗漏或误判，需通过原文出处核对。正文输出、手工修正、请求诊断、摘要压缩与生成过程的详细说明见 [使用指南](docs/USAGE.md)。

最早的 Dramatron 移植框架、旧 v0.8／Reborn 简化版及任务 v2 已退出内置目录。四份直接移植版（Dramatron 3.1、v0.8、Reborn 2.3、Linux 1.3）改为[可选 JSON 文件](presets/README.md)，需要时自行导入，不随部署自动加载。提示词页面顶部可导入、导出当前项或导出全部提示词；任务单项导出附带搭配的通用预设，整套恢复先确认并在保存后生效。文件不含供应商密钥，详见[移植与使用说明](docs/TAVERN-PRESETS.md)。

## 数据与备份

自定义脚本、MCP 和技能用于正文写作与穿越体验，独立保存并全局生效。脚本运行在服务器，以服务账号权限执行；本地 MCP 依赖需自行安装，远程连接遵循出站来源规则。添加、测试、导入和渐进式披露的完整操作见 [工具与技能](docs/EXTENSIONS.md)。

- 默认数据保存在 `data/`，不进入 Git。供应商密钥在服务端加密，页面仅显示是否已保存。
- 新目录初始化私有权限，已有目录先检查，合规时不重复修改；日常运行无需管理员／root。不合规且无权修复时会提示一次性处理，见 [数据权限与迁移](docs/DEPLOYMENT.md#数据权限与迁移)。
- 完整作品导出为 `.ai-novel.json.gz`，包含原文件、正文、故事线、历史资料、图片及其剧情关联、模型输出、任务进度和正文草稿；恢复时建立独立作品。正文也可单独导出 TXT。
- 作品备份包含作者秘密和请求素材，不包含登录凭据、供应商密钥或全局提示词设置。提示词预设可以独立导入导出。
- 迁移整个服务时，**停止服务后备份完整数据目录或 Docker 卷**，保留 `.encryption-key`，否则无法解密已保存的模型密钥。
- 删除作品无法撤销，需要保留时先备份。确认后会清理该作品的原文、正文、全部故事线、历史资料、任务和模型输出。

文件大小、恢复边界及删除中断处理见 [使用指南的备份说明](docs/USAGE.md#数据与备份)。
