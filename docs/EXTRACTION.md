## 当前流程

1. 保留已建立的章节与 5,500 字片段边界，未完成任务可沿用原进度。
2. 给提取模型当前编号片段及必要的已有名称提示，包括近期未具名人物；不混入未来预期规划或其他章节正文。伏笔索引只含正文中已埋下、尚未揭晓的条目。
3. 模型同时提取已发生的剧情摘要、人物、事件、状态及地理关系，引用只需标注段落编号；程序负责从当前片段取回精确依据。章节摘要包含因果、转折、人物变化和本章已揭晓的答案。
4. 本地补齐省略的可选字段，检查格式、引用、实体关联。原始响应、整理后的结果和人工修改分别留存。
5. 全部检查通过后，正文资料和任务进度一起提交；失败保留原文和输出，作者可以按条修正。

一次本地规范化不会再调用模型。正文、状态变化和实体关联的内容仍需模型理解，格式处理不能证明语义完全正确。

## 格式与证据规则

提取自动重试默认关闭，可在“设置 → 任务模型”设置额外请求次数和间隔。每个失败片段独立计数，保留每次响应与用量；已完成的片段和正文不重新生成。网络、超时、HTTP 5xx／408／429、格式或证据校验失败可按设置重试；配置、预算、其他 HTTP 4xx、存储错误、暂停、取消与版本变化会停止。次数耗尽后保留进度，支持手工修正或显式重试。服务重启不自动重复请求。完整操作见 [使用指南](USAGE.md#提取重试与剧情规划)。

- 顶层必须有字符串 `summary` 和数组 `entities`，不能把空对象或服务错误当作成功提取。`relations`、`foreshadows` 可省略为空数组。
- 实体仍需类型、名称。可省略别名、描述和事实列表；事实需有具体内容及可定位证据，关系需有两端名称、标签及证据。
- 省略的时间、确定性、可见性采用 `unknown`、`inference`、`secret`，避免未经说明就当成当前、确定、公开的信息；明确提供的错误值不会擅自改成默认值。
- 没有 `quote` 时按有效 `paragraph` 取回当前片段原文。长段拆成多个片段时，只使用模型本次看到的切片，不提前引用后半段。
- 旧引文存在时优先匹配原文；仅空白、引号差异可保守对齐，必须唯一定位。不会忽略字词差异、对错对象或任意挑选一处重复文字。
- 单个完整 JSON 代码块外不超过 512 字符的说明、代码围栏及字符串外的尾逗号可做有限格式处理；多个候选、结构截断、遗漏值仍报错，不凭空补数据。
- 关系或伏笔指向不存在、重名的实体时，集中展示关联问题。不能通过随意新建同名人物来掩盖问题。
- 同一批次先根据主名称与明确别名联系归并，再匹配历史资料。仅共享泛称、外貌相似、姓名包含或实体类型不同不会自动合并。明确的别名联系可归并旧重复条目，并重定向关系和伏笔关联；多个锁定身份或重名歧义需人工核对。归并继续保留引用、锁定与秘密可见性。
- 位置使用 `attribute: location`。明确的同类当前状态按原文章节和段落顺序更新，历史到达记录转为过去；回忆、未来目的地、推测及锁定冲突不会覆盖已经确认的位置。

## 剧情、伏笔与地图

`summary` 按片段顺序存入当前章节的剧情摘要，在剧情页按章展示，供规划和续写使用。它记录已发生的剧情，未发生剧情的预期规划独立保存，粗大纲已移除；整理原小说不额外生成未来规划。已揭晓或已放弃伏笔保留在历史记录中，默认界面及待处理上下文只显示未揭晓条目，模型的重复提及不会自动重新打开同名线索。

世界资料卡片固定高度，只预览部分内容，点击打开完整资料与出处。地图只展示地点之间的地理关系，明确方位可影响相对排布，未知方位只表示连接，不构造精确坐标或距离。人物当前位置在图外单独显示。摘要、伏笔状态与位置事实都属于故事版本，回退、修订或从旧章节分支时读取当时的快照。

已有资料不会因升级自动重新调用模型。后续提取遇到明确的别名联系时可以归并旧重复条目；没有身份依据的旧资料仍需作者用“合并”确认，暂停任务与已保存进度保持原样。

## 手工修正

作者打开任务的“模型输出 / 手工修正”后，默认看到中文表单。按提示定位错误卡片，修改内容或选择原文段落；可以使用整段原文，也可以选中其中一部分作为证据。修改引用之前先核对事实本身，删除没有依据的错误条目。

“保存并校验应用”保存修改并执行本地检查。成功后任务完成或暂停，需继续整理后续片段时再手动继续。“重试”则会产生新的模型请求。原始响应始终只读，可下载；高级 JSON 仅作为完整结构与语法修复入口。

## 验证边界

程序及浏览器测试使用中性文本、本地模拟模型和独立数据库，覆盖简化结果一次通过、精确证据回填、含糊引用拒绝、人工修正、响应留存及不增加模型调用。它们不等于同一真实模型的成功率评测，也不证明资料语义正确率。

## 人物资料维护

人物提取使用 gender（性别）、bloodline（血统）、identity（身份）、能力与性格等资料属性，不把吃饭、赶路等普通行动逐条存入角色经历；普通行动归入章节剧情摘要，重大事件用 major_event。未知字段留空，不能编造。能力和性格可用 ability:archery、personality:courage 等稳定细分属性，后续更新同一属性，其他能力继续保留。

当前明确资料随章节、段落更新，旧状态保留为历史，人物简介从当前资料字段与重大事件汇总。nameStatus=placeholder 表示暂称；仅在明确的名称或别名身份桥下升级为 confirmed 真名，旧暂称移入 aliases，真名不再只挂在别名中。锁定实体及事实保留作者确认内容。isMain 用于主要人物识别；已有作者主次选择优先，提取不能自行覆盖。

正文生成与资料提取为不同任务。正文生成完成即可阅读、编辑或重新生成；后台提取仍按片段持久化，失败只重试提取。重新生成从目标章之前新建分支，取消旧后台任务后其迟到响应只能作为输出记录留存，不能覆盖任何故事资料。
