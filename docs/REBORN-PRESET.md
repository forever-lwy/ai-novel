## 配套任务与角色

选择 **Reborn 2.3 通用防截断与破限**，再分别选择 **默认正文写作 v2 · 框架协作**、**默认资料提取 v2 · 框架协作** 和 **默认摘要压缩 v2 · 框架协作**，保留“跟随当前通用预设”，最后保存设置。

通用层负责虚构任务的直接交付与完整结果承载，不指定固定身份或文风。任务 v2 各用一条系统职责和一条用户输入：正文负责文笔、逻辑、文风及 RPG 主持边界；提取负责当前片段证据、身份、可见性及固定字段；压缩只处理已发生摘要及因果。去掉为分隔素材而伪造的助手确认回合，材料和本次要求在同一用户消息内明确分段。

任务插槽是编排位置，不是一条发送给模型的消息；其存储中的 role 只为兼容旧格式，编译时保留任务各块原有角色。界面显示“任务插槽／保留任务各块角色”，不再提供会造成误解的角色选择。作者自定义的多角色任务仍按原顺序展开。

结果内容与提交通道分别规定：写作生成正文，提取生成资料对象，压缩生成 text 对象；工具、普通文本或原生 Schema 决定如何提交。工具 JSON 使用统一的 `TOOL_JSON_INSTRUCTION`，预算、预览和实际发送不再额外追加直接返回原始 JSON 的旧指令。原生 `submit_extraction` 和 JSON Schema 优先，不再包一层正文工具。

任务 v2 可以搭配其他框架或独立使用；旧 Dramatron 的分段辅助结构仍由其开关控制。Reborn 默认开启工具承载，正文可明确改为普通文本；资料的原生输出模式优先。改变预设不改已经发出的请求或保存的 RPG 续接状态。

## 升级、恢复与验证范围

新增内置版本不会替换当前选择、旧预设、作者内容或明确的通用引用。`general.catalogVersion=2` 记录提供过 Reborn，已有 v0.8 的版本 1 保持兼容；`taskCatalogVersions` 分别记录三个任务已经提供过 v2。保存后删除不会自动补回，同 ID 的作者版本不覆盖；达到 20 份预设或 700000 字节总容量上限时延后补入，腾出容量后重开设置可再次检查，各任务独立处理。

“恢复默认框架／恢复默认版本”可以指定内置版本，替换当前预设内容而保留名称，保存后生效。导入导出使用已有格式，任务导出附带实际搭配的框架，不带供应商密钥。

本地测试验证编排、开关、过滤、持久化、四协议真实本地 HTTP 请求和内层工具执行；没有验证真实供应商上的破限、防空回或截断改善率。工具承载不能提高模型输出上限、阻止网络断流或保证模型调用意愿，失败仍保留输出且不隐式重发。具体结果见 [验收记录](VALIDATION.md)。
