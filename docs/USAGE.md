# 使用指南

日常创作、模型设置、任务恢复与备份的详细说明。运行方式见 [README](../README.md)，当前能力与验证边界见 [项目状态](../PROJECT-STATUS.md)。

## 使用顺序

1. 新建作品，点击书架或工作台的“设置”进入设置页面。在“供应商连接”添加服务地址、协议和密钥，再切换到“任务模型”，为正文写作、剧情规划、资料提取分别选择供应商与模型。选择供应商后会自动获取上游模型列表，也可以直接填写自定义模型名。
2. 原创输入设定后即可写作，无需先生成规划；导入作品上传 TXT／EPUB，检查分章，再开始整理。
3. 每次生成打开新章，正文像聊天一样实时流式显示，刷新后可恢复查看。作者视图另有“生成过程”，可查看模型公开返回的思考内容，以及工具调用的参数、结果和完成状态；详情默认折叠，生成结束后仍可回看。过程记录不进入正文、剧情提取或正文导出，阅读视图不返回这些记录。正文完成立即保存，资料提取另起后台任务；失败后只重试资料整理。继续写下一章前需完成上一章资料整理；不满意可点击“重新生成”，后台尚未完成时可选择等待，或放弃后台任务并生成新分支，原线正文保留。
4. 世界资料使用等高卡片，点击条目或“查看详情”展开完整描述、事实与出处，可纠正资料或合并别名。地点关系图只展示地理地点、区域与连接；人物当前位置单独显示。
5. 从章节结尾建立分支。修改较早章节会自动另开修订线，回退版本会同时恢复正文和资料。

书架中每部作品都有“删除”入口，确认后永久删除该小说的原文文件、正文、全部故事线与历史版本、世界资料、剧情规划、伏笔、任务和模型输出。删除会先停止该作品的后台任务，其他作品和供应商设置保留；需要保留的作品请先进入工作台下载备份，删除无法撤销。

阅读模式默认不返回预期规划、伏笔答案、秘密资料或未来事实；“查看作者资料”显式进入作者视图。作者可以人工修改、锁定资料。AI 提取仍可能遗漏或误判，应通过出处核对，程序校验不能替代语义判断。

导入与正文整理会同时提取已发生的剧情摘要，在“剧情与伏笔 → 摘要与预期规划”按章展示。剧情页分开维护已发生的摘要与未发生的预期规划；章节写出后对应规划移出未来列表。伏笔手记默认显示尚未揭晓的线索，已揭晓与已放弃条目可从历史入口查看。回退或切换旧章节分支时，摘要、资料、伏笔与位置一起恢复。

写作默认完整带入世界观和基本规则、主要人物资料、未揭晓伏笔、最近三章全文、完整剧情摘要与当前章预期规划；不截短最近正文或默默遗漏旧摘要。配角档案、地点或物品详情及更久远的全文，通过模型的查询工具按需读取，检索固定在本次写作的起始版本。搜索多个词时，工具推荐使用 `keywords` 数组，例如 `["林舟","老吴"]`，命中任一项即返回；原有 `query` 字符串也支持空格、逗号等分隔。要检索完整短语，可将它作为数组的一项。主要人物可在世界资料中勾选；作者明确取消勾选的配角不会自动加入。

摘要太长时，可在剧情页生成压缩候选；超过规划模型单次窗口的摘要会分段处理，再合并压缩，最多三轮，已完成片段可恢复。检查、编辑后点击“确认使用压缩摘要”；确认前继续使用原摘要，原分章摘要始终保留。超过单次上下文上限会停止并提示，不自动压缩、不降低输出上限。

人物档案按姓名、性别、血统、能力、性格、身份及当前状态持续更新；未知信息不猜测，经历只保留重大事件，普通行动放剧情摘要。能力与性格使用稳定的细分属性，更新某一能力不会覆盖其他能力。暂称人物有明确身份联系并获知真名后，真名升级为主名称，暂称转入别名；锁定名称由作者决定。

## 模型服务

| 协议 | API 前缀示例 |
| --- | --- |
| OpenAI Chat Completions | `https://api.openai.com/v1` |
| OpenAI Responses | `https://api.openai.com/v1` |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta` |
| Claude Messages | `https://api.anthropic.com/v1` |

填写 API **前缀**，程序仅追加所选协议的相对路径，不自动补 `/v1`。兼容网关可以填写自定义前缀。Chat 协议可选择 `max_tokens` 或 `max_completion_tokens`，程序只发送选定的一种；Responses 使用其对应的输出控制字段。具体型号是否支持所选参数，需以服务返回为准。

供应商连接保存协议、地址和密钥。同一个供应商可供三个任务使用不同模型；生成参数、输出上限和上下文上限在任务模型选择下方设置，按“任务用途＋供应商＋模型名称”分别保存。正文写作、剧情规划、资料提取即使使用同一供应商的同一模型，也各自保存参数；在同一任务中切换模型后再选回会恢复原设置。模型列表按当前供应商草稿查询，无需先保存；列表不可用或网关没有列出所需别名时，仍可填写自定义模型名。切换任务供应商后需重新选择或填写模型，程序不会替你选择列表中的第一项。旧版连接中的模型名和生成参数会转入原任务使用的模型；旧版跨任务共用的模型参数会分别复制给各任务，密钥继续保留。

密钥在服务端加密保存，页面只返回“已保存”状态。连接测试会发起一次真实模型请求；失败不自动重试。完整作品备份不包含服务密钥、登录密码或会话。

### 任务提示词与编排

在“设置 → 提示词编排”中，分别编辑正文写作、剧情规划、资料提取和摘要压缩的提示词。每个任务可以保存多份预设并选择当前使用的一份；预设独立于供应商和模型，摘要压缩仍使用规划模型。所有修改点击“保存设置”后生效，后续任务请求使用当前预设，已经发出的请求和已保存结果保持原记录。旧配置自动补入原有默认提示词。

设置页按“供应商连接”“任务模型”“提示词编排”切换，切换分类保留草稿；“保存设置”统一保存全部修改。未保存的设置离开时会提示，保存失败保留草稿并定位问题分类。点击“返回作品”回到原书架或工作台，当前章节、作者视图及未保存正文继续保留。

每个预设由消息块组成，可以新增、复制、删除、启停，拖动或用上下箭头排序，修改 `system/user/assistant` 角色和完整内容。正文块可按原创、续写、同人、改写设置适用模式。用 `{{变量名}}` 插入作品标题、本次要求、世界观、主要人物、摘要、最近正文等资料；完整 `{{context}}` 与分项变量同时提供，按需要选择，重复插入会重复占用上下文。自定义变量可保存风格规则和常用要求，值仅替换一次，素材内部的花括号不会再次展开。

“编译预览”使用可编辑的示例素材，不调用模型。任务的实际输入可在模型输出的请求诊断中核对。Chat / Responses 保留消息顺序；Gemini / Claude 将系统块按相对顺序合并到协议的系统提示区，其余消息保留顺序。规划、提取和压缩仍要求 JSON，并继续检查字段、证据及故事版本；编辑提示词不能改变程序接受的输出结构。

可独立导入导出本项目的预设 JSON，导入新增预设，恢复默认只重置当前预设。预设文件不带供应商连接或 API 密钥，全局提示词配置不包含在单作品备份中。每个任务最多 20 份预设，每份最多 80 块，全部提示词文本最多 700000 UTF-8 字节。这里支持分块编排、变量和模式条件，尚不兼容 SillyTavern 的预设格式、脚本宏或 World Info 自动匹配。设计参考 [SillyTavern Prompt Manager](https://docs.sillytavern.app/usage/prompts/prompt-manager/)。

### 生成参数与思考设置

选择模型后可展开“生成参数与思考设置”。新模型的通用默认值为温度 `1`、Top P `1`、存在与频率惩罚 `0`、单次最大输出 `4096` tokens、上下文上限 `64000` tokens、超时 `180` 秒、非流式；可一键恢复这些默认值。思考模式、随机种子、Top K 和停止序列默认不发送。已有模型的设置保持原值，主动清空的可选参数不会在保存后重新补值。不同型号支持范围不同，服务不支持的可选项可清空。

上下文上限限制每次请求的预估输入与完整预留输出之和；单次输出按该模型保存的上限发送，不因历史用量缩小。可选项留空表示不发送，数字 `0` 会保留。温度、Top P、Top K、停止序列、随机种子及重复惩罚按协议显示和发送。

- OpenAI Chat / Responses：设置思考等级；Chat 可选择 `max_tokens` 或 `max_completion_tokens`，只发送选定的一种。
- Gemini：选择思考等级或 token 预算，二者互斥；另可选择是否返回思考摘要（`includeThoughts`），摘要不会进入正文或提取结果。只能展示接口实际返回的思考文本或摘要；未开启返回、模型未提供或返回加密签名时，不补造思考内容。具体范围取决于模型；Gemini 3 系列优先使用等级，并先保留服务默认的采样参数。
- Claude：思考支持服务默认、关闭、手动预算、自适应，另可设置 effort。手动预算至少 1024，且小于保存的单次输出上限；开启思考时的采样限制由界面和服务端检查。
- 正文写作固定流式；规划、资料提取与连接测试沿用各自的返回方式设置。流式持续接收事件，完整后校验入库；接收中断保留已收到的生成草稿与诊断，不隐式重发生成请求。尚未保存成章时，手动继续或重试会重新生成，不从断点续写；需要保留中断草稿时先下载。流式不能保证绕过网关自己的请求时限。写作模型须支持对应协议的工具调用。
- 超时可设为 1–3600 秒，留空为 180 秒。实际发送参数可在请求诊断中查看。

任务配置中的“保存并测试连接”使用该任务选择的供应商与模型，按当前参数和输出上限发送一次短提示词请求，成功和失败均展示本次诊断。不同模型和网关支持的参数不同；程序不会为了重试而自行替换模型或参数。自动获取模型列表不发送生成请求。

导入按章节和片段整理，不把全书反复发给模型。任务累计输入与输出仅作用量统计，不再设置累计限额；旧设置中的任务用量上限会被忽略并在保存时移除。单次请求的预估输入与完整预留输出超出上下文上限时，会在请求发送前停止并保留进度，调整上下文上限或减少本次输入后可手动重试。服务重启后运行中的任务转为暂停，需要手动恢复；模型调用过程中断的请求可能已由供应商计费，重试可能再次产生用量。

如果任务提示“模型服务请求失败（HTTP 500）”，表示模型接口返回了错误，具体原因需要结合服务商状态或配置判断。可先用“保存并测试连接”检查连接；恢复后在原任务上点击“重试”，不需要重复上传小说。“取消任务”会停止后续处理，已经保存的原文和资料仍保留。

对比“测试场成功、任务失败”时，进入作者任务的“模型输出 / 手工修正 → 实际请求与连接诊断”，核对 URL、协议、模型、流式开关、温度/思考、最终输出上限、耗时与响应头。请求在发送前留存，空响应、连接失败和超时也有记录；旧记录没有快照时会明确说明。密钥已脱敏，但请求正文含作者素材，下载后应按作品资料保管。

诊断还会显示模型结束原因及输入拦截原因，区分已返回正文、模型拦截、输出截断、成功但没有正文和服务错误。网关只有 500／502 错误包、没有返回模型反馈时，不推断为引用错误或内容拦截；需要核对网关的实际出站响应。已收到的原响应仍保留，未收到的正文不能恢复。

AxonHub 的渠道测试场是管理接口，可直接指定渠道；普通 API 使用自己的模型映射和路由，不能仅按提示词相同认定等价。排查步骤和源码依据见 [模型连接排查](MODEL-CONNECTIONS.md)。不要把浏览器 Cookie 或 Cloudflare 登录凭据复制进模型配置。

### 校验失败时手工修正

在**作者视图 → 任务 → 模型输出 / 手工修正**中，可以查看每次响应、最初的模型文本、具体错误字段及对应原文。模型响应会先保存，再检查 JSON、字段和引用；未通过校验的内容不会直接写进世界资料。

- 默认使用可视化表单，直接修改摘要、人物或地点、事实、关系及伏笔，不需要了解 JSON。点击问题旁的定位入口，找到对应字段。
- 引用不符时，先核对这条事实是否正确，再选择支持它的原文段落；可以直接使用该段，也可以在段落中选取一段文字作为引文。没有原文依据的条目应删除或改正，不能只换一段无关文字让它通过。
- 关系名称应选择已识别的资料名称或别名；“过去”用于回忆，“当前”用于此时发生的状态，无法确认时选“不明确”。秘密与未来安排不要标成公开事实。
- “高级 JSON”保留完整结构编辑。语法损坏、无法显示表单时，可在这里修复格式，再返回可视化编辑；没有收到的内容不会由程序猜测补齐。
- 原始响应只读保存，修正另存；即使修正后仍失败，提交的修改也会保留。
- 点击“保存并校验应用”只做本地处理，不调用模型，也不增加模型用量。通过后，任务完成或保持暂停；需要处理后续片段时再点击“继续”。
- “重试”会重新调用模型，与手工修正不同。
- 旧任务没有自动留存记录时，使用“粘贴历史响应”导入已有结果；支持完整 Gemini、OpenAI、Claude 响应及直接输出的 JSON / 正文。
- 已取消、已完成、进度已变化或故事线版本不匹配的输出仍可查看和下载，不能覆盖当前故事。

输出仅在作者视图开放，已知密钥及响应中的凭据字段会脱敏。收到的响应限制为 16 MiB；超限、截断或网络中断时保留已收到的部分并标记不完整。连接失败且服务没有返回任何内容时，没有可保存的模型输出。

提取流程让模型提供段落编号，由程序从当前片段取回精确原文，不再要求模型逐字重抄引文。旧响应仅有空白或引号差异、且能唯一定位时，会自动对齐并记录说明；错字、无法定位或有歧义的引用仍需修正。省略的可选字段采用保守默认值，未来规划不混入提取上下文。详细规则与 AiNiee 参考记录见 [提取流程说明](EXTRACTION.md)。

## 插画与故事图册

先在设置的“生图与自动插画”选择供应商、图片接口和图片模型。图片任务复用供应商的服务地址与密钥，独立于文字模型；可填写自定义模型名称。支持 OpenAI 兼容 Images、Gemini GenerateContent 和 Together Images，服务地址填写 API 前缀。OpenAI 兼容服务须返回 Base64 图片，参考图输入使用 `images/edits`；Gemini 使用文字及内联图片；Together 独立发送 `response_format=base64`，不套用 OpenAI 的返回格式值。

每次绘图先由文字 AI 把资料、剧情、作者要求和画风整理成专用提示词，描述主体、外貌衣着、动作、镜头、构图、环境、光线及氛围；CG 选取一个关键画面，避免直接把剧情摘要丢给图片模型。可选择“生图提示词优化供应商／模型”，不指定时先用规划模型，再用写作模型；填写优化模型名也可沿用默认的文字供应商。文字模型的参数按规划用途读取，输入及完整输出预留都计入单次上下文。没有可用文字模型或优化失败时，任务失败并保留素材，不跳过这一步直接绘图。优化本身会调用文字模型并产生用量。

“提示词优化系统要求”影响文字 AI 如何编写提示词；“统一画风”是作品的绘制风格；Gemini 的“图片模型系统提示词”直接发送到图片模型的原生系统区。这三个设置分别生效。

设置按所选协议和已知型号显示及校验参数：

| 接口／型号 | 可设置的主要生成参数 |
| --- | --- |
| OpenAI GPT Image | 尺寸、质量、背景、PNG／JPEG／WebP、JPEG／WebP 压缩、内容审核；支持该字段的型号可设参考图保真度。GPT Image 2 系列可自定义宽高，并遵守型号的尺寸限制；2.5 的指定型号额外提供更高质量等级。 |
| Gemini Nano Banana 2（`gemini-3.1-flash-image`） | 画幅比例、512／1K／2K／4K 分辨率、minimal／high 思考等级、系统提示词、温度、Top P／Top K、种子、输出 Token 上限、思考返回及 JPEG 输出。 |
| Gemini 3 Pro Image／2.5 Flash Image | 参数按型号区别显示；Pro 提供 1K／2K／4K 与 high 思考等级，2.5 不提供思考等级或分辨率选项。 |
| Together | 宽高或画幅比例、种子、PNG／JPEG、采样步数、引导强度、负面提示词、提示词增强及供应商检查开关按型号显示。FLUX.2 Dev／Flex 支持步数和引导强度，Pro 不发送这两个参数；Kontext 使用比例并支持一张参考图。 |

尺寸、画幅比例及有此能力的分辨率可以选择“AI 自行决定”，文字 AI 根据画面从支持的范围中选择，程序校验后才生图；手动固定值优先。未知或自定义网关型号按所选协议处理，具体能力需供应商确认。每个图册任务输出一张图片，返回格式固定为内联 Base64，未提供实时图片分块或搜索素材工具。非支持参数会在设置保存或请求前报错；切换接口／型号会清理不兼容的图片参数，优化模型与画风草稿保留。

接口格式及型号差异依据 [OpenAI 图片接口](https://developers.openai.com/api/reference/resources/images/methods/generate)、[Gemini GenerateContent 图片指南](https://ai.google.dev/gemini-api/docs/generate-content/image-generation)、[Gemini REST 参数](https://ai.google.dev/api/generate-content) 和 [Together 参数兼容表](https://docs.together.ai/docs/inference/images/parameters)。这里保留旧型号名称供兼容网关使用，不代表已退役型号仍可在官方服务调用。

- 新人物立绘：自动立绘默认开启，配置完成后，写作 AI 可以调用 `generate_character_portrait` 请求。正文保存和资料整理确认人物后，图片绑定到人物资料；未调用工具的新人物也会依据提取后的资料补充立绘。已有立绘的人物不会每章重复自动绘制。
- 剧情 CG：保存正文后，点击“生成本章 CG”；也可选中正文，再生成对应片段的 CG。图片保存章节、选段范围和用于绘制的原文，图册可跳回关联剧情。先保存编辑草稿并完成或取消当前文字任务，再手动生图。
- 人物参考：默认开启“CG 自动参考出场人物的已有立绘”。文字 AI 根据对应场景选择参考人物，程序匹配当前版本中已完成的立绘并实际发送图片，同时说明图片和人物的对应关系。自动 CG 遇到同批正在绘制的相关人物立绘时会等待；失败的立绘不会阻塞 CG，人物仍可依据资料绘制。图片编辑先占用原图参考位置，其余位置受型号人数／参考图上限约束。可在作者的“生图详情”查看实际参考人物。
- 资料与地图：人物及各种实体的资料里提供生图按钮，依据现有资料绘制；地点关系页面可以依据地点资料和地理关系绘制地图。
- 重绘与修改：图册或人物资料可重新绘制，也可选择已有图片用“AI 修改”，填写修改要求。修改时实际发送原图作为参考，新图单独保存，旧图保留。失败、中断或版本过期时可手动重试；取消后不会继续应用结果。
- 图片选择：同一人物／实体、地图或同一章的同一 CG 剧情范围可以保存多张图片，点击“启用图片”选择一张，其他同组图片转为未启用；也可单独停用当前图片。已有启用图片时，重新绘制的新图先保留为未启用，人物资料继续展示作者选中的图片。第一次为该对象绘图，成功后启用；旧作品未保存选择时，兼容采用最新的成功图片。
- 未启用图片：仍保留在作者图册，可以预览、重新绘制或删除，但不会进入提示词优化的图片候选、实际 AI 图片输入或 CG 参考，也不在阅读视图展示。用已有图进行 AI 修改前需先启用原图。任务中途更换参考图或停用它时，旧结果不能继续发起后续生图请求；重试会按当前选择整理提示词。
- 删除图片：作者点击删除后先确认，可取消；删除从当前故事线的图册及启用选择中移除，失败时保留当前图片。被历史版本或其他故事线引用的像素仍保留，以便回退和备份；删除启用图片不会自动改用旧图，需要保留展示时另选一张启用。已生成 CG 的历史参考照片停用或移出当前图册，不会让 CG 本身消失；秘密和未来资料的过滤继续生效。
- 查看图片：点击缩略图打开时，生图详情默认收起，点击“生图详情”才展开；图册的“生图详情”入口会直接展开详情。可放大、缩小、适应窗口或按原始大小查看，大图可以滚动移动。全屏按钮进入浏览器全屏，不支持时使用页面全屏；进入全屏会收起详情，图片区占满屏幕。全屏控件是独立小按钮，鼠标靠近上下边缘显示对应按钮，离开约 1.5 秒后自动隐藏；点击信息按钮查看图片标题，点击缩放百分比按钮打开滑块。隐藏的控件不挡图片拖动；键盘 Tab 可唤出并操作按钮，触屏轻点图片可显示控件。全屏时点击“生图详情”以浮层查看提示词与参数，不挤占图片区；退出全屏保持详情收起。可以退出全屏或关闭查看窗口，切换故事线／视图时会清理查看状态。
- 自动 CG：在设置中开启“场景变化或大场面时自动生成 CG”，写作 AI 会得到 `generate_scene_cg` 工具及调用要求。模型负责判断场景变化和大场面，请求必须引用本章实际正文；是否覆盖每个场景取决于文字模型的工具调用能力。本章最多接受 12 个自动插画请求，可在正文完成后手动补图。

正文页面显示关联插画；“故事图册”集中查看当前故事线的 CG、人物立绘、实体图片和地图，并区分已启用图片和未启用的暂存版本。作者的“生图详情”显示优化后的最终提示词、本次实际参数和参考人物。图片选择和移除与故事版本一起保存，分支、回退及备份恢复保留对应选择。插画请求不进入小说正文、剧情提取或 TXT 导出。生图在独立任务中进行，不因图片失败重新生成正文，也不会自动重试可能计费的图片请求。优化完成后保存结果，图片失败重试可复用提示词；资料、图片型号、固定构图参数或启用的参考图已改变时重新优化。服务重启后中断图片任务转为暂停，作者确认重试后才再次请求。

Together 参考图接口的官方文档确认 `image_url`／`reference_images` 为 URL 输入。本工作台以 `data:` 内联发送已有私有图片，不额外上传到公开网站；该输入已在本地模拟接口验证，真实 Together 服务是否接受仍需实机验收。若上游拒绝，会保留错误，不自动移除参考图或重复调用。Gemini 的内联图片、提示词与系统区合计有请求大小边界，超过时停止请求。

图片引用与正文、资料一起进入版本快照，分支和回退会恢复对应图册。正文或资料已变更时，迟到图片标为版本过期，不能覆盖新版本；可以基于当前资料重绘。阅读视图由服务端过滤涉及秘密、未来资料或作者补充要求的图片，并隐藏图片提示词与生成错误。图像生成有自由发挥，作者应核对外貌和地图关系，图片不会反向改写已确认资料。

## 数据与备份

- 作品备份为 `.ai-novel.json.gz`，包含原文件、章节、各故事线、历史资料、图片内容及其资料和剧情关联、模型输出及手工修正、未完成任务的进度、流式正文草稿及作者工作过程，恢复时建立独立作品。旧版 JSON 备份也可读取；恢复的运行中任务转为暂停，手动继续后接着整理。图片失败或中断不会自动重新调用生图服务。
- 正文可以单独导出 TXT。作品备份包含作者秘密，请按私人创作资料保管。
- 迁移整个服务时，停止服务后备份整个数据目录或 Docker 卷，尤其保留 `.encryption-key`；该文件用于解密模型密钥。
- TXT 支持 UTF-8、UTF-16 和 GB18030；EPUB 按阅读顺序提取正文，不加载外部资源，不处理 DRM。上传小说最大 32 MiB，解压后最多 128 MiB，正文最多 2000 万字。
- 作品备份上传最大 128 MiB，外层解压最大 512 MiB，单个历史世界状态解压最大 64 MiB；长期积累超出单作品备份范围时使用完整服务目录备份，不删除或截断历史。
- 删除作品时，原文件会临时移入数据目录的 `deleted-sources/`，数据库事务失败时恢复原位置，成功后清理。服务意外中断时，下次启动按数据库记录恢复或继续清理；文件被系统占用而未能清理时，会记录日志并在下次启动重试。
