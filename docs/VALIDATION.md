## 2026-09-30：失败任务无法重试或取消

- 原因：前端通用请求函数为没有正文的 POST 也设置了 `Content-Type: application/json`，Fastify 在执行任务动作前返回 400。此前直接调用后端的测试没有复现浏览器实际发送的请求头，未覆盖这一问题；退出登录也受影响。
- 修复：仅在有非空 JSON 字符串正文、且调用者未指定类型时添加 JSON 请求头；保留调用者提供的 Headers，文件上传继续由浏览器设置 multipart boundary。
- 用户现有任务的原始失败记录为模型接口 HTTP 500，与按钮请求被拒绝是两个问题。本次仅只读检查真实任务和导入进度，不重新调用真实模型、不修改用户任务或原文。
- 定向验证：`tests/client-api.test.ts` **5/5 通过**；系统 Edge 故障流程 **1/1 通过**。实际浏览器上传测试 TXT，遇到本地模拟 HTTP 500 后，重试与取消请求均返回 200；取消后原文和已导入正文仍完整，退出登录也正常。生产构建与类型检查通过。

## 设计限制

- 单用户、单服务实例；后台任务保存在数据库。前端以轮询获取进度，不依赖页面保持打开。
- 原文上传后立即可预览与下载，工作故事线随章节整理逐步可用；只有已整理的章节边界可以安全分支。
- 地图为地点关系图，不产生没有依据的精确坐标。
- 资料准确性取决于文本质量和模型表现。程序检查格式、原文引用和关联，无法证明小说理解完全正确。
- 实际模型价格因供应商而异；界面记录 token 用量，不将未知价格伪装成精确金额。
- 绘图与游戏规则尚未实现；本阶段不以占位响应模拟这些能力。
