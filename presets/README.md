# 可选预设文件

以下是适配本项目的预设 JSON，**不会自动加入内置目录，也不会打进前后端运行包**：

- [Dramatron 3.1 · 原版结构](tavern-dramatron-v31.json)
- [v0.8 · 原版结构](tavern-v08.json)
- [Reborn 2.3 · 原版结构](tavern-reborn-v23.json)
- [Linux 1.3 · 原版结构](tavern-linux-v13.json)

在“设置 → 提示词编排”点击顶部“导入预设或任务提示词”，选择其中一份，确认可编辑的名称，再点击“保存设置”。文件会自动识别为通用预设；重复导入会新增副本。推荐搭配各任务内置的 v3 提示词。

单项导出保留全部消息块、开关、变量及结果工具设置；任务提示词还附带搭配的通用预设。可以使用“导出全部提示词”备份全部预设、四类任务及其选择，再通过同一导入入口恢复。整套导入会先确认替换当前编辑，保存后才写入数据库。两类文件都不包含供应商连接和 API 密钥。

这些是本项目格式，并非任意酒馆 JSON 导入器。原始脚本不会执行。来源、适配范围与验证边界见 [移植说明](../docs/TAVERN-PRESETS.md)。
